# Fichiers source compacts

L'énoncé complet et le corrigé sont dans le **Guide stagiaire**, section « Fichiers source compacts ». Les corrigés y sont regroupés en fin de document.

## En deux lignes

`Bienvenue.java` ne contient qu'un commentaire. Écrire le programme qui affiche `Bonjour depuis un fichier source compact`, sans classe, sans `main` statique et sans import.

## Lancer

```
java Bienvenue.java
```

Aucune compilation préalable. En l'état, le fichier répond `error: no class declared in source file`.
